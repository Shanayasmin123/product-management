# MERN Product Management System

This project is a full-stack MERN application built for a MERN Stack Internship assignment.

## Features
- User Registration & Login
- JWT Authentication
- Role-based Access Control (Admin/User)
- Admin can add, edit, and delete products
- Users can view products

## Tech Stack
- MongoDB
- Express.js
- React.js
- Node.js

## Installation

### Backend
cd backend
npm install
npm start

### Frontend
cd frontend
npm install
npm start
